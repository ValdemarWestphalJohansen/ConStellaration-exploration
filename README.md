# ConStellaration exploration

A short data analysis of Proxima Fusion's open [ConStellaration dataset](https://huggingface.co/datasets/proxima-fusion/constellaration), looking at trade-offs between confinement (QI), stability (vacuum well) and geometry in ~160,000 stellarator shapes.

Open `stellarator_tradeoffs.ipynb` to see the analysis and plots.

**To run it:** `pip install polars numpy matplotlib`, then uncomment the download lines in the second code cell the first time to fetch the data from Hugging Face.
